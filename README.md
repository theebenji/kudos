# Kudos

An employee recognition app: send kudos to coworkers, and see what each person has received and given.

A pnpm + Turborepo monorepo with a Next.js web app, a GraphQL API (Yoga + Pothos), PostgreSQL (Drizzle), and a CSS Modules + Radix component library with Storybook.
